# Plan: Forgot Password Implementation

This plan outlines the steps to implement a "Forgot Password" flow with email OTP verification and password reset.

## Phase 1: Backend Implementation

1. **Update `backend/routes/authRoutes.js`**:
    - Add `POST /api/admin/forgot-password`:
        - Validate email.
        - Check if admin user exists.
        - Generate 6-digit OTP and expiry (10 mins).
        - Save OTP to user document.
        - Send OTP via `sendOTPEmail`.
    - Add `POST /api/admin/reset-password`:
        - Validate email, OTP, and new password.
        - Verify OTP and expiry.
        - Update user password (hashing is handled by User model pre-save hook) and clear OTP fields.

2. **Update `backend/utils/emailService.js`**:
    - Modify `sendOTPEmail` to accept an optional `subject` and `title` to distinguish between "Verification" and "Password Reset".

## Phase 2: Frontend (Flutter) Implementation

1. **Update `lib/providers/auth_provider.dart`**:
    - Add `forgotPassword(email)`: Calls `/forgot-password`.
    - Add `resetPassword(email, otp, newPassword)`: Calls `/reset-password`.

2. **Create/Update Screens in `lib/views/auth/`**:
    - **Update `login_screen.dart`**: Link "Forgot Password?" button to `ForgotPasswordScreen`.
    - **Create `forgot_password_screen.dart`**: Email input to trigger OTP, then navigate to `OtpScreen`.
    - **Update `otp_screen.dart`**: Add a parameter or check to decide whether to navigate to Dashboard (signup flow) or `ResetPasswordScreen` (forgot password flow).
    - **Create `reset_password_screen.dart`**: New password input with eye toggle.

## Verification Section

1. **Backend Test**:
    - Use Postman to call `/forgot-password`.
    - Verify OTP is logged in console (mock mode) or sent to email.
    - Use Postman to call `/reset-password` with the received OTP.
    - Attempt login with the new password.

2. **Frontend Test**:
    - Click "Forgot Password" on login screen.
    - Enter registered email and click "Send OTP".
    - Enter OTP on the next screen.
    - Enter new password and confirm.
    - Verify redirect to login screen with a success message.
    - Log in with new credentials.
